# Getting started

To use AsyncMqttClient, you need:

- An ESP8266 or ESP32 board
- A current Arduino framework and PlatformIO installation
- Basic knowledge of the Arduino environment

## Installing AsyncMqttClient

PlatformIO is the maintained installation path. Add the library to the target
environment:

```ini
lib_deps =
  labodj/AsyncMqttClient-esphome@^2.1.3
```

PlatformIO installs the platform-specific ESP32Async transport automatically.
For reproducible builds, replace the version range with an exact release
archive or commit archive from
[this repository](https://github.com/labodj/async-mqtt-client).

For a manual Arduino installation, download the corresponding
[GitHub release](https://github.com/labodj/async-mqtt-client/releases/latest)
and install the transport for the target platform as well:

- [ESP32Async/ESPAsyncTCP](https://github.com/ESP32Async/ESPAsyncTCP) for ESP8266
- [ESP32Async/AsyncTCP](https://github.com/ESP32Async/AsyncTCP) for ESP32

## Fully featured sketches

See the [ESP8266 example](../examples/FullyFeatured-ESP8266/FullyFeatured-ESP8266.ino)
or the [ESP32 example](../examples/FullyFeatured-ESP32/FullyFeatured-ESP32.ino).

Do not call blocking functions such as `delay()` from asynchronous callbacks.
See the [API reference](2.-API-reference.md) for the callback signatures.
